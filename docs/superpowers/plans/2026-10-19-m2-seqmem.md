> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 在 `focus-trainer` 里实现第 2 个游戏「序列记忆」（视觉工作记忆广度，spec §3.3）：格子依次高亮 → 按同样顺序（逆序档倒着）点回，整串点对加长、点错结束并回放一次正确序列，并把模块注册进 `GAMES`。

## 本计划写死的裁定（执行者不必再决定，但要在 review 时核对）

- **R-1 回放时间归引擎**：序列的亮/灭、答后定格、错误后的正确序列回放，全部由 `start(now)` / `tick(now)` 推进；`view.ts` 里出现任何 `setTimeout` / `setInterval` / `Date.now()` 即为返工。
- **R-2 相邻重复非法、非相邻重复合法**：`makeSpan` 用拒绝采样保证 `seq[i] !== seq[i-1]`（spec:97），同格隔位再现是合法序列；`size² === len` 时必然出现重复（Task 1 Step 1 有一条 pigeonhole 断言把它钉死）。
- **R-3 `result()` 拷贝口径**：`trials.map((t) => ({ ...t }))` + `metrics` 字面新建。理由：`TrialRecord` 的自定义字段只放标量（`span`/`dir`/`taps`），不放 `seq`/`taps` 数组，所以浅拷贝即完整拷贝；数组留在引擎内部会让 `session.ts:112` 的 `{ ...t }` 变成共享引用（M1 未决项 T40 类问题）。回忆进度要显示，走 `snapshot().tapped`（快照里 `slice()`），不进 trial。
- **R-4 一试次 = 一条序列**：`trials` 每条序列一项，不是每格一项；`rt` = 该串最后一次点击 − 播放结束时刻（`showEndAt`），永不超时所以永不为 `null`。
- **R-5 无回忆超时**：spec:96 没给回忆时限。加时限等于用「思考慢一点」惩罚用户并直接判 0 分，故不设；`recallMs` 进 trial 与结算指标，卡住不动由退出按钮兜底（见「需要执行时才能发现的事」Q-2）。
- **R-6 答错 = 立刻结束本轮，但先回放再 `isDone()`**：点错那一格 → 定格 400ms → 原序回放一次 → 回放的 `showEndAt` 到点才设 `endAt`。这样「本轮结束」对用户是可学习的，不是黑屏；引擎没有 abort API，`endAt` 只在 tick 里落，不需要钳制。
- **R-7 `timingValid` 做，且只覆盖播放相位**：seqmem 是 spec:361 点名的时序关键游戏（「序列的高亮播放」）。`tick` 里若上一帧到当前帧的间隔 `> FRAME_MS` 且该帧处于 `show`/`replay`，则 `timingOk = false`。`recall`/`reveal` 不判（用户在想，帧稀疏不是卡顿）。Task 4 有阈值两侧的用例，Task 6 有走通 `SessionRunner` 补轮分支的端到端用例。
- **R-8 播放期间的点击一律忽略**：`phase !== 'recall'` 或 `endAt !== null` 时 `input()` 直接 return，不记错、不记 trial。视图不做相位判断、不禁点击，引擎是唯一权威。
- **R-9 `roundNo` 不参与出题**：形参与 `GameEngine.configure` 逐字一致（必填），序列生成只吃 `(level, seed)`，与舒尔特同一口径；`seed` 在 `configure` 里只 `createRng(seed)` 一次，本轮 7 条序列按顺序消费同一条 rng 流。

import { randInt } from '../../core/rng';
import type { Rng } from '../../core/rng';
import type { Outcome, RoundRecord, RoundResult, SummaryItem } from '../../core/types';

export interface SeqmemLevel {
  size: number;
  dir: 'fwd' | 'rev';
  l0: number;
  onMs: number;
  gapMs: number;
}

// spec §3.3 第 103–112 行档位表：档 | 方向 | 起始长度 L0 | 网格 | 亮 d ms | 间隔 g ms
export const SEQMEM_LEVELS: readonly SeqmemLevel[] = [
  { size: 3, dir: 'fwd', l0: 3, onMs: 800, gapMs: 300 },
  { size: 3, dir: 'fwd', l0: 4, onMs: 750, gapMs: 280 },
  { size: 4, dir: 'fwd', l0: 4, onMs: 700, gapMs: 260 },
  { size: 4, dir: 'fwd', l0: 5, onMs: 650, gapMs: 240 },
  { size: 4, dir: 'fwd', l0: 6, onMs: 600, gapMs: 220 },
  { size: 5, dir: 'fwd', l0: 6, onMs: 550, gapMs: 200 },
  { size: 5, dir: 'fwd', l0: 7, onMs: 500, gapMs: 180 },
  { size: 4, dir: 'rev', l0: 4, onMs: 650, gapMs: 240 },
  { size: 4, dir: 'rev', l0: 5, onMs: 600, gapMs: 220 },
  { size: 5, dir: 'rev', l0: 6, onMs: 500, gapMs: 200 },
];

export const SEQMEM_MAX_LEVEL = SEQMEM_LEVELS.length;
export const SEQMEM_SPAN_GROWTH = 6;

export function seqmemLevel(level: number): SeqmemLevel {
  if (!Number.isInteger(level) || level < 1 || level > SEQMEM_MAX_LEVEL) {
    throw new RangeError(`seqmem level out of range: ${level}`);
  }
  return SEQMEM_LEVELS[level - 1];
}

// 刺激起始异步时间（SOA）= 亮 d + 间隔 g；每档字面值来自 spec 表，不在引擎里二次硬编码。
export function soaMs(lv: SeqmemLevel): number {
  return lv.onMs + lv.gapMs;
}

export function capSpan(lv: SeqmemLevel): number {
  return lv.l0 + SEQMEM_SPAN_GROWTH;
}

// 拒绝采样生成一条序列：只排除「相邻同格」（spec:97），隔位重复合法（裁定 R-2）。
// 每个候选恰好消费一次 randInt，所以一条 rng 流上第 k 条序列的内容与前面消费的次数无关紧要。
export function makeSpan(rng: Rng, size: number, len: number): number[] {
  const total = size * size;
  const out: number[] = [];
  while (out.length < len) {
    const c = randInt(rng, 0, total - 1);
    if (out.length > 0 && c === out[out.length - 1]) continue;
    out.push(c);
  }
  return out;
}

// spec:114–115：s ≥ 2 → pass；s = 0 → fail；s = 1 → hold。score01 = min(1, s / 3)。
export function judgeSeqmem(r: RoundResult): { outcome: Outcome; score01: number } {
  const s = r.metrics.spansCorrect;
  let outcome: Outcome = 'hold';
  if (s >= 2) outcome = 'pass';
  else if (s === 0) outcome = 'fail';
  return { outcome, score01: Math.min(1, s / 3) };
}

// 结算只统计 counted 轮（作废/补轮为 false）。fwdSpan/revSpan 每轮只有一侧非 0，
// 因为档位决定方向；取 max 就是「本次训练答对的最长序列长度，正序逆序分开」（spec:116）。
export function summarizeSeqmem(rounds: readonly RoundRecord[]): Record<string, number> {
  const counted = rounds.filter((round) => round.counted);
  if (counted.length === 0) return { fwdSpan: 0, revSpan: 0, spans: 0, spansCorrect: 0, avgRecallMs: 0 };
  const spansCorrect = counted.reduce((sum, round) => sum + round.metrics.spansCorrect, 0);
  const recallSumMs = counted.reduce((sum, round) => sum + round.metrics.recallSumMs, 0);
  return {
    fwdSpan: Math.max(...counted.map((round) => round.metrics.fwdSpan)),
    revSpan: Math.max(...counted.map((round) => round.metrics.revSpan)),
    spans: counted.reduce((sum, round) => sum + round.metrics.spans, 0),
    spansCorrect,
    avgRecallMs: spansCorrect === 0 ? 0 : Math.round(recallSumMs / spansCorrect),
  };
}

export function formatSeqmemSummary(s: Record<string, number>): SummaryItem[] {
  return [
    { label: '正序最大广度', value: s.fwdSpan > 0 ? `${s.fwdSpan} 格` : '—' },
    { label: '逆序最大广度', value: s.revSpan > 0 ? `${s.revSpan} 格` : '—' },
    { label: '答对序列', value: `${s.spansCorrect} / ${s.spans} 条` },
    { label: '平均回忆用时', value: s.avgRecallMs > 0 ? `${(s.avgRecallMs / 1000).toFixed(1)} 秒` : '—' },
  ];
}

// 从 from 起按帧网格推进，返回相位第一次满足 cond 的那一帧
function tickUntil(
  eng: SeqmemEngine,
  from: number,
  cond: (s: SeqmemSnapshot) => boolean,
  limit = 120000,
): { t: number; s: SeqmemSnapshot } {
  let t = from;

    eng.tick(t);
    const s = eng.snapshot();
    if (cond(s)) return { t, s };
    if (t >= from + limit) return { t, s };

import { createRng } from '../../core/rng';
import type { Rng } from '../../core/rng';
import type { GameEngine, InputEvent, RoundResult, TrialRecord } from '../../core/types';
import { capSpan, makeSpan, seqmemLevel, soaMs } from './rules';
import type { SeqmemLevel } from './rules';

// spec:240/361 帧间隔阈值（严格「大于」才作废）；REVEAL_MS 是答对/答错后的定格时长
export const FRAME_MS = 50;
export const REVEAL_MS = 400;

export type SeqmemPhase = 'idle' | 'show' | 'recall' | 'reveal' | 'replay' | 'done';

export interface SeqmemSnapshot {
  size: number;
  cells: number;
  phase: SeqmemPhase;
  dir: 'fwd' | 'rev';
  span: number;
  capSpan: number;
  spanNo: number;
  correct: number;
  litIndex: number | null;
  tapped: number[];
  wrongIndex: number | null;
  elapsedMs: number;
  done: boolean;
}

export class SeqmemEngine implements GameEngine<SeqmemSnapshot> {
  private level = 1;
  private seed = 0;
  private lv: SeqmemLevel = seqmemLevel(1);
  private rng: Rng = createRng(0);
  private seq: number[] = [];
  private span = 0;
  private pos = 0;
  private spanNo = 0;
  private correctSpans = 0;
  private bestSpan = 0;
  private recallSumMs = 0;
  private phase: SeqmemPhase = 'idle';
  private tapped: number[] = [];
  private wrongIndex: number | null = null;
  private startAt = 0;
  private now = 0;
  private lastFrameAt = 0;
  private showStartAt = 0;
  private showEndAt = 0;
  private revealUntil = 0;
  private endAt: number | null = null;
  private timingOk = true;
  private trials: TrialRecord[] = [];

  // 形参与 GameEngine.configure 逐字一致。roundNo 只进 SessionRunner 的记账，不参与出题（裁定 R-9）。
  configure(level: number, seed: number, roundNo: number): void {
    const lv = seqmemLevel(level);
    this.level = level;
    this.seed = seed;
    this.lv = lv;
    this.rng = createRng(seed);
    this.trials = [];
    this.correctSpans = 0;
    this.bestSpan = 0;
    this.recallSumMs = 0;
    this.spanNo = 0;
    this.wrongIndex = null;
    this.endAt = null;
    this.phase = 'idle';
    // 作废契约（spec:292）：SessionRunner.voidCurrentRound() 不通知引擎，重开轮只调 configure + start，
    // 所以帧计时基准、播放游标、定格窗口都必须在这里归零，否则上一轮的时间会漏进 snapshot.elapsedMs。
    this.startAt = 0;
    this.now = 0;
    this.lastFrameAt = 0;
    this.showStartAt = 0;
    this.showEndAt = 0;
    this.revealUntil = 0;
    this.timingOk = true;
    this.newSeq(lv.l0);
  }

  start(now: number): void {
    this.startAt = now;
    this.now = now;
    this.lastFrameAt = now;
    this.beginShow(now);
  }

  input(e: InputEvent): void {
    // 裁定 R-8：非回忆相位的点击一律忽略（不记错、不进 trial、不推进 now）。Task 3 在此门后填判定。
    if (this.phase !== 'recall' || e.kind !== 'cell' || this.endAt !== null) return;
  }

  tick(now: number): void {
    this.now = Math.max(this.now, now);
    if (this.phase === 'show' && this.now >= this.showEndAt) this.phase = 'recall';
  }

  snapshot(): SeqmemSnapshot {
    return {
      size: this.lv.size,
      cells: this.lv.size * this.lv.size,
      phase: this.phase,
      dir: this.lv.dir,
      span: this.span,
      capSpan: capSpan(this.lv),
      spanNo: this.spanNo,
      correct: this.correctSpans,
      litIndex: this.litAt(),
      tapped: this.tapped.slice(),
      wrongIndex: this.wrongIndex,
      elapsedMs: this.now - this.startAt,
      done: this.endAt !== null,
    };
  }

  isDone(): boolean {
    return this.endAt !== null;
  }

  result(): RoundResult {
    throw new Error('seqmem result() is implemented in Task 3');
  }

  // 一条 rng 流贯穿整轮：第 k 条序列的内容只取决于前面消费过多少次 randInt（裁定 R-9）。
  private newSeq(len: number): void {
    this.span = len;
    this.seq = makeSpan(this.rng, this.lv.size, len);
    this.spanNo += 1;
    this.pos = 0;
    this.tapped = [];
    this.wrongIndex = null;
  }

  private beginShow(at: number): void {
    this.phase = 'show';
    this.showStartAt = at;
    this.showEndAt = at + (this.span - 1) * soaMs(this.lv) + this.lv.onMs;
  }

  // 亮格由帧时间算出，不是存出来的：一帧内跨两个窗口也不会漏播。
  private litAt(): number | null {
    if (this.phase !== 'show' && this.phase !== 'replay') return null;
    const soa = soaMs(this.lv);
    const i = Math.floor((this.now - this.showStartAt) / soa);
    if (i < 0 || i >= this.seq.length) return null;
    return this.now < this.showStartAt + i * soa + this.lv.onMs ? this.seq[i] : null;
  }
}

```ts
import type { GameView, InputEvent } from '../../core/types';
import type { SeqmemSnapshot } from './engine';

// 顶部提示行：所有措辞只由快照决定，视图不持有任何时间/相位游标（裁定 R-1）。
function infoText(s: SeqmemSnapshot): string {
  if (s.phase === 'done') return `本轮结束 · 答对 ${s.correct} 条`;
  if (s.phase === 'replay') return '正确顺序回放 · 看清它';
  if (s.phase === 'reveal') {
    return s.wrongIndex === null
      ? `第 ${s.span} 格对了 · 下一条更长`
      : `点错了 · 本轮结束（答对 ${s.correct} 条）`;
  }
  if (s.phase === 'recall') return `${s.dir === 'fwd' ? '按原顺序' : '倒着'}点回 ${s.span} 格 · 已点 ${s.tapped.length}`;
  return `记住顺序 · 第 ${s.spanNo} 条 · ${s.span} 格`; // idle / show
}

export function createSeqmemView(host: HTMLElement, emit: (e: InputEvent) => void): GameView<SeqmemSnapshot> {
  const root = document.createElement('div');
  root.className = 'seqmem';
  const info = document.createElement('div');
  info.className = 'seqmem-info';
  const grid = document.createElement('div');
  grid.className = 'seqmem-grid';
  root.append(info, grid);
  host.append(root);

  let layoutCells = 0;
  let buttons: HTMLButtonElement[] = [];

  const onDown = (ev: PointerEvent): void => {
    const hit = ev.target instanceof Element ? ev.target.closest('button[data-i]') : null;
    if (!(hit instanceof HTMLButtonElement)) return;
    ev.preventDefault();
    emit({ kind: 'cell', index: Number(hit.dataset.i), t: ev.timeStamp });
  };
  grid.addEventListener('pointerdown', onDown);

  return {
    render(s) {
      // cells = size²，档位变了才重建；同一档内复用节点，只切 class（每帧都要 render）
      if (s.cells !== layoutCells) {
        layoutCells = s.cells;
        grid.style.gridTemplateColumns = `repeat(${s.size}, 1fr)`;
        buttons = Array.from({ length: s.cells }, (_, i) => {
          const b = document.createElement('button');
          b.type = 'button';
          b.className = 'seqmem-cell';
          b.dataset.i = String(i);
          b.textContent = String(i + 1);
          return b;
        });
        grid.replaceChildren(...buttons);
      }
      const picked = new Set(s.tapped);
      buttons.forEach((b, i) => {
        // done 之后 SessionRunner 停止喂帧，lit/wrong 只能靠 !s.done 兜住，否则会挂到用户点「继续」
        b.classList.toggle('lit', s.litIndex === i && !s.done);
        b.classList.toggle('wrong', s.wrongIndex === i && !s.done);
        b.classList.toggle('picked', picked.has(i));
      });
      info.textContent = infoText(s);
    },
    destroy() {
      grid.removeEventListener('pointerdown', onDown);
      root.remove();
    },
  };
}
```

import { describe, expect, it } from 'vitest';
import { SessionRunner } from '../../core/session';
import type { GameState, SessionRecord } from '../../core/types';
import { GAME_IDS } from '../../core/types';
import { SeqmemEngine } from './engine';
import type { SeqmemSnapshot } from './engine';
import { seqmem } from './index';
import { seqmemLevel } from './rules';

const STEP = 10;
const INIT: GameState = { gameId: 'seqmem', level: 1, passStreak: 0, failStreak: 0, lastPlayedDayKey: null };

function range(from: number, to: number): number[] {
  const out: number[] = [];
  for (let t = from; t <= to; t += STEP) out.push(t);
  return out;
}

const snapOf = (runner: SessionRunner): SeqmemSnapshot => runner.engine.snapshot() as SeqmemSnapshot;

// 只在 runner 处于 playing 时才真正转发帧；phase 一旦离开 playing，tick 就是 no-op（session.ts:77）
function frames(runner: SessionRunner, list: readonly number[]): number[] {
  const lit: number[] = [];
  for (const t of list) {
    runner.tick(t);
    const s = snapOf(runner);
    if (s.litIndex !== null && s.litIndex !== lit[lit.length - 1]) lit.push(s.litIndex);
  }
  return lit;
}

// 采样到「相位离开 show」为止：亮格顺序 + 那一帧的时刻
function watchOnce(runner: SessionRunner, from: number): { seq: number[]; t: number } {
  const seq: number[] = [];
  let t = from;
  for (;;) {
    runner.tick(t);
    const s = snapOf(runner);
    if (s.litIndex !== null && s.litIndex !== seq[seq.length - 1]) seq.push(s.litIndex);
    if (s.phase !== 'show') return { seq, t };
    t += STEP;
  }
}

// 推进到下一条序列开播（或本轮结束）
function advance(runner: SessionRunner, from: number): number {
  let t = from;
  for (;;) {
    runner.tick(t);
    const s = snapOf(runner);
    if (s.phase === 'show' || s.done) return t;
    if (t >= from + 200000) return t;
    t += STEP;
  }
}

function playRound(runner: SessionRunner, from: number, mode: 'clean' | 'wrong-first'): void {
  const lv = seqmemLevel(runner.snapshot().level);
  const total = lv.size * lv.size;
  let t = from;
  while (runner.snapshot().phase === 'playing') {
    const shown = watchOnce(runner, t);
    // 「必定错」的第一击：逆序档的期望首格是 seq 的末格，不能拿 seq[0] 去 +1
    const expectFirst = lv.dir === 'fwd' ? shown.seq[0] : shown.seq[shown.seq.length - 1];
    const order = mode === 'clean' ? lv.dir === 'fwd' ? [...shown.seq] : [...shown.seq].reverse() : [(expectFirst + 1) % total];
    let at = shown.t + 50;
    for (const cell of order) {
      if (runner.snapshot().phase !== 'playing') break; // 上一击已经把本轮结束掉了
      runner.input({ kind: 'cell', index: cell, t: at });
      at += 50;
    }
    t = advance(runner, at);
  }
}

// 一整次训练：轮间是 'tap'，所以由测试自己 beginRound 并把绝对时刻往前推
function session(
  seed: number,
  level: number,
  modes: readonly ('clean' | 'wrong-first')[],
): { record: SessionRecord; state: GameState } {
  const runner = new SessionRunner(seqmem, { ...INIT, level }, 'plan', seed, seed);
  let t = 0;
  runner.beginRound(t);
  for (const mode of modes) {
    playRound(runner, t, mode);
    t += 1000000;
    if (!runner.isFinished()) runner.beginRound(t);
  }
  // finish() 只能调一次（session.ts:102 的 saved 闸门），所以取一份再拆
  const out = runner.finish('2026-10-19');
  return { record: out.record, state: out.state };
}

- **Q-2 回忆阶段没有超时**（裁定 R-5）：用户停在 `recall` 不动，本轮会一直挂着，只能靠「退出」或切后台作废。要不要加超时/跳过按钮是产品问题，要回 spec 谈，本计划不擅自实现。
- **Q-3 节奏手感**：`REVEAL_MS = 400`、答错后「红 400ms → 回放」的衔接、高档位 SOA 680–700ms 在低刷新率屏上是否够看清，只能真机调。改动要同步改 Task 4 的字面量测试。
- **Q-4 5×5 的可点性**：390px 宽下 25 格每格约 60px，接近 `--tap: 48px` 的下限；若误点率高，先考虑加 `gap`/减小圆角，不要改档位表的网格尺寸。
- **Q-5 帧间隔误杀率**：低端机上 50ms 阈值会不会频繁把播放轮判成 `timingValid = false`（`MAX_RETRIES = 3` 后按 hold 计入），需要看真机一轮训练里 `lastInvalid` 出现几次；误杀严重时是阈值问题，不是引擎问题。
- **Q-6 期望测试计数**：本计划写的 11 / 18 / 9 / 5（seqmem 合计 43）与全仓约 180 条以实测为准；有变异自检失败就补断言，不许删用例凑数。
- **Q-7 序列内容的金标准**：测试刻意不把 mulberry32 的具体出题结果写成字面数组（那要先跑一遍代码），改用「同 seed 两次一致 + 换 seed 不同 + 相邻不等 + 帧时刻表」四重约束。若以后要加金标准快照，另开任务，别在 M2 里塞。
- **Q-8 `ability` 字段名**：本计划钉成 `'工作记忆'`（与舒尔特 `'持续注意'` 同为 4 字，M3 五维雷达图用）。若 M3 的雷达图另有命名约定，只改 `index.ts` 这一处与 Task 6/7 的两条断言。
