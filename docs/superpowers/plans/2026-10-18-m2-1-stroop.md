## 对 spec 第 3.2 节沉默处的裁定（K1–K10）

spec 第 3.2 节有几处按字面无法直接实现，本计划按下述裁定落地。**后续 M2 计划不要重新解释这些裁定**，遇到同类表述直接引用本节编号。

- **K1 「每试次 X% 概率切换」= 试次边界上的马尔可夫翻转，不是独立抽签。** 第 1 试次恒为「按颜色」；此后每个试次边界以 `switchProb` 翻转规则。理由：马尔可夫链的平稳分布是 50/50，与 X 无关，X 控制的是**切换频率**（任务切换代价），这正是该档想练的东西；若读成独立抽签，「25%」会让 75% 的试次都是「按颜色」，第 5 档反而比第 4 档更不混合，且档位 5/6/7 的「25%/35%/50%」失去单调意义。两条判别测试（Task 2）：40 个种子下 `按字义` 占比落在 [0.35, 0.65]（独立抽签实现给出 ≈0.25，直接被杀），以及第 5 档切换次数显著小于第 7 档。
- **K2 冲突比例 = 每轮配额，不是每试次概率。** `conflictCount(level) = Math.round(conflictRatio × 12)`，得到逐档字面数组 `[6,6,7,7,8,8,8,9,9,10]`。理由：一轮只有 12 个试次，spec 的 60%/65%/70%/80% 换成试次数是 7.2/7.8/8.4/9.6，本来就是分数；配额化后每轮冲突数确定，测试才可断言。选 `Math.round` 而非 `Math.floor`：第 5 档 7.8→8、第 10 档 9.6→10 更贴近 spec 数字（floor 会得 7 和 9）。冲突试次的**位置**由 `shuffle(rng, 0..11).slice(0, n)` 决定。
- **K3 按钮位置「固定」= 一轮一次带种子的乱序并沿用 12 个试次**，不是按 红绿蓝黄 的原生顺序排（否则「固定」档的位置预期等于人肉背答案，且跨轮没有差异，难度断崖）。「每试次打乱」= 每个试次重做一次乱序。
- **K4 「干扰色」文字 = 带种子的循环位移**：`textInk[j] = slots[(j + shift) % n]`，`shift = randInt(rng, 1, n-1)`。这样保证没有「按钮文字颜色 == 文字含义」的自匹配（位移量非 0 且循环置换无不动点），并且 4 个颜色各出现一次（不位移就可能漏色，视觉上像少了选项）。非干扰色档位 `textInk = null`，视图渲染白色。
- **K5 「任一组为空时显示「—」」的空值哨兵 = `NaN`。** `summarizeStroop` 返回的仍是 `Record<string, number>`（`GameModule.summarize` 的契约），无正确试次时 `meanRtMs = NaN`，干扰组为空时 `interferenceMs = NaN`；`formatStroopSummary` 用 `Number.isFinite` 判断后渲染「—」。不能用 `-1` 或 `0` 之类的哨兵：干扰效应合法地为负（反向斯特鲁普效应本来就在测量范围内），任何数值哨兵都可能撞上真实值。**实现细节**：`summarizeStroop` 的返回类型写 `Record<string, number>`，不要定义 `interface StroopSummary`——TS 里 interface 没有隐式索引签名，赋给 `Record<string, number>` 会 TS2345，`type` 别名才可行；本计划直接用 `Record<string, number>`，少一个符号。
- **K6 试次时间线**：`start(now)` 那一帧进入注视（`phaseStart = now`）；`now - phaseStart >= 300` 的那一帧进入反应窗并把 `onset` 记成**该帧时间戳**；`rt = e.t - onset`；`now >= onset + timeoutMs` 判超时（`rt = null`、`correct = false`）；作答或超时后进入反馈，`now - phaseStart >= 200` 时推进；第 12 试次反馈结束 → `done`，`result().metrics.timeMs = endAt - startAt`。注视期间按钮已渲染但不可作答（`phase !== 'respond'` 的 `input` 直接吞掉），与 spec「注视点 300ms（规则横幅此时已更新）」一致。
- **K7 「正确率」结算口径**：`accuracy = 计分轮正确试次数 ÷ 计分轮试次总数`（4 轮就是 ÷48），保留原始比值不取整；只有 `formatStroopSummary` 做 `Math.round(accuracy * 100)`。理由：spec 只说「正确率」，取整方向必须在计划里定死，`Math.floor` 会把 5/12 = 41.67% 显示成 41%。
- **K8 今日计划的「注册表增长重算」只在一种情况下发生**：当天计划**还没打完**、且计划里的游戏数少于 `PLAN_SIZE`、且传入的 `gameIds` 含有计划里没有的 id。三条同时成立才重建；重建保留已有的 `completed`（只保留仍在新计划里的项），**绝不撤销已拿到的打卡**（既不删 `completed`，也不改历史日期的计划，`streak` 因此不可能倒退）。其余情况一律返回当天原计划。
- **K9 M1 的 UI 测试拿 `'stroop'` 当「未注册游戏」样本**：`src/ui/pages/play.test.ts` 第 477 行 `it('游戏未注册时先返回首页，不读库也不渲染')` 里是 `h.render('stroop')`。`stroop` 一注册，这条就变成「断言一个已注册游戏会返回首页」，会以「期望 `replaceState` 被调用但没被调用」的形式炸掉。Task 3 Step 6 把它换成 `'seqmem'`（M2-2 才注册，此刻仍是 `undefined`），用例意图不变。同一份样本数据在 `src/core/scheduler.test.ts`、`src/ui/today.test.ts`、`src/core/storage.test.ts` 里也出现，但那些地方的 `'stroop'` 只是 standings / 记录的 id，跟注册表无关，**一个字都不改**。
- **K10 本计划不给 `view.ts` 写穷尽单测**（沿用 M1 的取舍：DOM 桩只测容易静默失效的分支），第 9/10 档的干扰色文字与乱序位置由 Task 8 的浏览器验收实测。

  const f = (t: number): number => (t > 0.008856 ? Math.cbrt(t) : 7.787 * t + 16 / 116);
  const fx = f(x);
  const fy = f(y);
  const fz = f(z);
  return [116 * fy - 16, 500 * (fx - fy), 200 * (fy - fz)];
}

function deltaE(a: string, b: string): number {
  const p = labOf(a);
  const q = labOf(b);
  return Math.hypot(p[0] - q[0], p[1] - q[1], p[2] - q[2]);
}

  { options: 4, timeoutMs: 1000, ruleMode: 'perTrial', switchProb: 0.5, conflictRatio: 0.75, shuffleSlots: true, distractorText: false },
  { options: 4, timeoutMs: 850, ruleMode: 'perTrial', switchProb: 0.5, conflictRatio: 0.75, shuffleSlots: true, distractorText: true },
  { options: 4, timeoutMs: 700, ruleMode: 'perTrial', switchProb: 0.5, conflictRatio: 0.8, shuffleSlots: true, distractorText: true },
];

export const STROOP_MAX_LEVEL = STROOP_LEVELS.length;

export function stroopLevel(level: number): StroopLevel {
  if (!Number.isInteger(level) || level < 1 || level > STROOP_MAX_LEVEL) {
    throw new RangeError(`stroop level out of range: ${level}`);
  }
  return STROOP_LEVELS[level - 1];
}

export function conflictCount(level: number): number {
  return Math.round(stroopLevel(level).conflictRatio * TRIALS_PER_ROUND);
}

export function roundRule(lv: StroopLevel, roundNo: number): StroopRule {
  if (!Number.isInteger(roundNo) || roundNo < 1) {
    throw new RangeError(`stroop roundNo out of range: ${roundNo}`);
  }
  if (lv.ruleMode !== 'perRound') return 'color';
  return roundNo % 2 === 1 ? 'color' : 'word';
}

export function judgeStroop(r: RoundResult): { outcome: Outcome; score01: number } {
  const correct = r.metrics.correct;
  let outcome: Outcome = 'hold';
  if (correct >= 10) outcome = 'pass';
  else if (correct <= 7) outcome = 'fail';
  return { outcome, score01: correct / TRIALS_PER_ROUND };
}

interface StroopTrialView {
  correct: boolean;
  rt: number | null;
  rule: StroopRule | undefined;
  conflict: boolean | undefined;
}

// TrialRecord 的额外字段走索引签名，类型是 unknown；这里一次性收窄成本游戏的视图，
// 免得在 filter 里反复对 unknown 做 === 比较。
function view(t: TrialRecord): StroopTrialView {
  return {
    correct: t.correct,
    rt: t.rt,
    rule: t['rule'] as StroopRule | undefined,
    conflict: t['conflict'] as boolean | undefined,
  };
}

function mean(list: number[]): number {
  if (list.length === 0) return Number.NaN;
  return list.reduce((a, b) => a + b, 0) / list.length;
}

export function summarizeStroop(rounds: readonly RoundRecord[]): Record<string, number> {
  const cells = rounds.filter((r) => r.counted).flatMap((r) => r.trials.map(view));
  const correct = cells.filter((c) => c.correct);
  const rtOf = (list: StroopTrialView[]): number[] =>
    list.map((c) => c.rt).filter((v): v is number => typeof v === 'number');
  const colorCorrect = correct.filter((c) => c.rule === 'color');
  const conflict = rtOf(colorCorrect.filter((c) => c.conflict === true));
  const consistent = rtOf(colorCorrect.filter((c) => c.conflict === false));
  const meanRtMs = mean(rtOf(correct));
  return {
    accuracy: cells.length === 0 ? 0 : correct.length / cells.length,
    meanRtMs,
    interferenceMs: conflict.length === 0 || consistent.length === 0 ? Number.NaN : mean(conflict) - mean(consistent),
  };
}

function msText(v: number): string {
  return Number.isFinite(v) ? `${Math.round(v)} 毫秒` : '—';
}

export function formatStroopSummary(s: Record<string, number>): SummaryItem[] {
  const interference = s.interferenceMs;
  const interferenceText = Number.isFinite(interference)
    ? `${Math.round(interference) > 0 ? '+' : ''}${Math.round(interference)} 毫秒`
    : '—';
  return [
    { label: '正确率', value: `${Math.round(s.accuracy * 100)}%` },
    { label: '平均反应时', value: msText(s.meanRtMs) },
    { label: '干扰效应', value: interferenceText },
  ];
}

function configured(level: number, seed: number, roundNo = 1): StroopEngine {
  const e = new StroopEngine();

// 于是「作答帧」总比 onset 晚一帧，rt 恰为 delayOf 给的毫秒数。
function finishRound(e: StroopEngine, delayOf: (s: StroopSnapshot) => number): RoundResult {
  let now = 0;
  while (!e.isDone()) {
    now += 100;
    const s = e.snapshot();
    if (s.phase === 'respond' && s.onsetMs !== null && now - s.onsetMs >= delayOf(s)) {
      e.input(choiceAt(correctSlot(s), now));
    }
    e.tick(now);
  }
  return e.result();
}

function playRound(level: number, seed: number, roundNo: number, delayOf: (s: StroopSnapshot) => number): RoundResult {
  const e = new StroopEngine();
  e.configure(level, seed, roundNo);
  e.start(0);
  return finishRound(e, delayOf);
}

先记下题面生成的 **rng 调用顺序**（后续任务的期望值都按它推，改动顺序会同时改乱 Task 2/Task 4 的字面断言）：
① 调色板 `shuffle(rng,[0,1,2,3])`（4 次消耗）→ ② 冲突试次位置 `shuffle(rng,0..11)`（11 次消耗）→ ③ 规则序列：`perTrial` 时每试次边界 1 次 `rng()`（第 1 试次不抽）→ ④ 位置「固定」时 `shuffle(rng,palette)` 一次 → ⑤ 逐试次：`pick` 取墨色 1 次，冲突再 `pick` 取词义 1 次 → ⑥ 位置「打乱」时该试次 `shuffle` 一次 → ⑦ 干扰色档位该试次 `randInt` 取位移 1 次。

时间线（K6）导出的三个整数常量，Step 4 的断言就靠它们：
`onset₁ = 300`；`onsetₖ₊₁ = onsetₖ + delayₖ + FEEDBACK_MS + FIXATION_MS = onsetₖ + 500 + delayₖ`；`endAt = 6000 + Σ delay`（12 试次全按时作答，delay 是「onset 之后多久作答」）。第 1 档全程不作答：`endAt = 300 + 11×(2000+500) + 2000 + 200 = 30000`。

import { createRng, pick, randInt, shuffle } from '../../core/rng';
import type { GameEngine, InputEvent, RoundResult, TrialRecord } from '../../core/types';
import {
  STROOP_COLORS,
  TRIALS_PER_ROUND,
  conflictCount,
  roundRule,
  stroopLevel,
  type StroopLevel,
  type StroopRule,
} from './rules';

export const FIXATION_MS = 300;
export const FEEDBACK_MS = 200;

export type StroopPhase = 'fixation' | 'respond' | 'feedback' | 'done';

export interface StroopOption {
  colorIdx: number;
  label: string;
  textInk: number | null;
}

export interface StroopSnapshot {
  rule: StroopRule;
  phase: StroopPhase;
  word: number | null;
  ink: number | null;
  conflict: boolean | null;
  onsetMs: number | null;
  options: StroopOption[];
  trialNo: number;
  trialsTotal: number;
  correctCount: number;
  timeoutCount: number;
  feedbackChoice: number | null;
  feedbackOk: boolean;
  elapsedMs: number;
  done: boolean;
}

// 用 type 而不是 interface：要能隐式索引签名，才赋得进 TrialRecord（它带 [field: string]: unknown）。
type StroopTrialRec = {
  onset: number;
  rt: number | null;
  correct: boolean;
  rule: StroopRule;
  conflict: boolean;
  word: number;
  ink: number;
  choice: number;
  slots: number[];
  textInk: (number | null)[];
};

// 正确选项下标：按颜色取墨色，按字义取词义。刺激没出现的注视期没有正确答案。
export function correctSlot(s: StroopSnapshot): number {
  if (s.word === null || s.ink === null) throw new Error('stroop stimulus is not visible');
  return s.options.findIndex((o) => o.colorIdx === (s.rule === 'color' ? s.ink : s.word));
}

type RoundPlan = {
  rules: StroopRule[];
  words: number[];
  inks: number[];
  optionSets: StroopOption[][];
};

function buildPlan(level: number, seed: number, roundNo: number): RoundPlan {
  const lv = stroopLevel(level);
  const rng = createRng(seed);
  const n = lv.options;
  const palette = shuffle(rng, [0, 1, 2, 3]).slice(0, n);
  const conflicts = new Set(
    shuffle(rng, Array.from({ length: TRIALS_PER_ROUND }, (_, i) => i)).slice(0, conflictCount(level)),
  );

  const rules: StroopRule[] = [];
  let cur: StroopRule = 'color';
  for (let k = 0; k < TRIALS_PER_ROUND; k++) {
    if (lv.ruleMode === 'perTrial') {
      // K1：切换发生在试次边界，第 1 试次恒按颜色。平稳分布是 50/50，switchProb 管的是切换频率而非配比。
      if (k > 0 && rng() < lv.switchProb) cur = cur === 'color' ? 'word' : 'color';
      rules.push(cur);
    } else {
      rules.push(roundRule(lv, roundNo));
    }
  }

  const fixedSlots = lv.shuffleSlots ? null : shuffle(rng, palette);
  const words: number[] = [];
  const inks: number[] = [];
  const optionSets: StroopOption[][] = [];
  for (let k = 0; k < TRIALS_PER_ROUND; k++) {
    const ink = pick(rng, palette);
    words.push(conflicts.has(k) ? pick(rng, palette.filter((c) => c !== ink)) : ink);
    inks.push(ink);
    const slots = lv.shuffleSlots ? shuffle(rng, palette) : (fixedSlots ?? palette.slice());
    const shift = lv.distractorText ? randInt(rng, 1, n - 1) : 0;
    optionSets.push(
      slots.map((colorIdx, j) => ({
        colorIdx,
        label: STROOP_COLORS[colorIdx].name,
        textInk: lv.distractorText ? slots[(j + shift) % n] : null,
      })),
    );
  }
  return { rules, words, inks, optionSets };
}

export class StroopEngine implements GameEngine<StroopSnapshot> {
  private level = 1;
  private seed = 0;
  private roundNo = 1;
  private plan: RoundPlan = { rules: [], words: [], inks: [], optionSets: [] };
  private trialIdx = 0;
  private phase: StroopPhase = 'fixation';
  private phaseStart = 0;
  private onset: number | null = null;
  private startAt = 0;
  private now = 0;
  private endAt: number | null = null;
  private correctCount = 0;
  private timeoutCount = 0;
  private feedbackChoice: number | null = null;
  private feedbackOk = false;
  private trials: StroopTrialRec[] = [];

  // 形参与 GameEngine.configure 逐字一致。roundNo 在颜色认知不是纯记账：第 4 档的「每轮交替」要读它。
  configure(level: number, seed: number, roundNo: number): void {
    this.plan = buildPlan(level, seed, roundNo);
    this.level = level;
    this.seed = seed;
    this.roundNo = roundNo;
    this.trialIdx = 0;
    this.phase = 'fixation';
    this.onset = null;
    this.endAt = null;
    this.correctCount = 0;
    this.timeoutCount = 0;
    this.feedbackChoice = null;
    this.feedbackOk = false;
    this.trials = [];
    // 作废契约（spec 5.1）：SessionRunner.voidCurrentRound() 不通知引擎，重开轮只调 configure + start。
    // 时间基准必须一起归零，否则 start() 之前的 elapsedMs 与 onset 会把上一轮的用时漏进补轮。
    this.startAt = 0;
    this.phaseStart = 0;
    this.now = 0;
  }

  start(now: number): void {
    this.startAt = now;
    this.phaseStart = now;
    this.now = now;
    this.phase = 'fixation';
    this.onset = null;
  }

  input(e: InputEvent): void {
    if (e.kind !== 'choice' || this.phase !== 'respond' || this.endAt !== null) return;
    const picked = this.plan.optionSets[this.trialIdx][e.index];
    if (picked === undefined) return;
    const target =
      this.plan.rules[this.trialIdx] === 'color'
        ? this.plan.inks[this.trialIdx]
        : this.plan.words[this.trialIdx];
    const correct = picked.colorIdx === target;
    this.now = Math.max(this.now, e.t);
    this.pushTrial(e.t - (this.onset ?? this.now), correct, e.index);
    this.feedbackChoice = e.index;
    this.feedbackOk = correct;
    this.phase = 'feedback';
    this.phaseStart = this.now;
  }

  tick(now: number): void {
    this.now = Math.max(this.now, now);
    if (this.endAt !== null) return;
    if (this.phase === 'fixation') {
      if (this.now - this.phaseStart >= FIXATION_MS) {
        this.phase = 'respond';
        this.onset = this.now;
      }
      return;
    }
    if (this.phase === 'respond') {
      if (this.now >= (this.onset ?? this.now) + stroopLevel(this.level).timeoutMs) {
        this.pushTrial(null, false, -1);
        this.phase = 'feedback';
        this.phaseStart = this.now;
      }
      return;
    }
    if (this.phase === 'feedback' && this.now - this.phaseStart >= FEEDBACK_MS) {
      this.feedbackChoice = null;
      this.feedbackOk = false;
      this.onset = null;
      if (this.trialIdx === TRIALS_PER_ROUND - 1) {
        this.endAt = this.now;
        this.phase = 'done';
        return;
      }
      this.trialIdx += 1;
      this.phase = 'fixation';
      this.phaseStart = this.now;
    }
  }

  snapshot(): StroopSnapshot {
    const k = this.trialIdx;
    const hasTrial = k < this.plan.optionSets.length;
    // 词只在反应窗可见：spec「颜色词以某种墨色出现，直到作答或超时」
    const visible = hasTrial && this.phase === 'respond';
    const end = this.endAt ?? this.now;
    return {
      rule: this.plan.rules[k] ?? 'color',
      phase: this.phase,
      word: visible ? this.plan.words[k] : null,
      ink: visible ? this.plan.inks[k] : null,
      conflict: visible ? this.plan.words[k] !== this.plan.inks[k] : null,
      onsetMs: visible ? this.onset : null,
      options: hasTrial ? this.plan.optionSets[k].map((o) => ({ ...o })) : [],
      trialNo: Math.min(k + 1, TRIALS_PER_ROUND),
      trialsTotal: TRIALS_PER_ROUND,
      correctCount: this.correctCount,
      timeoutCount: this.timeoutCount,
      feedbackChoice: this.feedbackChoice,
      feedbackOk: this.feedbackOk,
      elapsedMs: Math.max(0, end - this.startAt),
      done: this.endAt !== null,
    };
  }

  isDone(): boolean {
    return this.endAt !== null;
  }

  result(): RoundResult {
    if (this.endAt === null) throw new Error('stroop round is not finished');
    return {
      level: this.level,
      seed: this.seed,
      trials: this.trials.map((t) => ({ ...t, slots: t.slots.slice(), textInk: t.textInk.slice() })),
      metrics: {
        correct: this.correctCount,
        timeouts: this.timeoutCount,
        trials: this.trials.length,
        timeMs: Math.round(this.endAt - this.startAt),
      },
      // spec 第 6 节：舒尔特与颜色认知只测反应时，不做帧间隔判定
      timingValid: true,
    };
  }

  private pushTrial(rt: number | null, correct: boolean, choice: number): void {
    const k = this.trialIdx;
    const options = this.plan.optionSets[k];
    this.trials.push({
      onset: this.onset ?? this.now,
      rt,
      correct,
      rule: this.plan.rules[k],
      conflict: this.plan.words[k] !== this.plan.inks[k],
      word: this.plan.words[k],
      ink: this.plan.inks[k],
      choice,
      slots: options.map((o) => o.colorIdx),
      textInk: options.map((o) => o.textInk),
    });
    if (correct) this.correctCount += 1;
    if (rt === null) this.timeoutCount += 1;
  }
}

import type { GameView, InputEvent } from '../../core/types';
import type { StroopSnapshot } from './engine';
import { STROOP_COLORS, WHITE_TEXT } from './rules';

export function createStroopView(host: HTMLElement, emit: (e: InputEvent) => void): GameView<StroopSnapshot> {
  const root = document.createElement('div');
  root.className = 'stroop';
  const rule = document.createElement('div');
  rule.className = 'stroop-rule';
  const word = document.createElement('div');
  word.className = 'stroop-word';
  const options = document.createElement('div');
  options.className = 'stroop-options';
  const info = document.createElement('div');
  info.className = 'stroop-info';
  root.append(rule, word, options, info);
  host.append(root);

  let layoutKey = '';
  let buttons: HTMLButtonElement[] = [];

  const onDown = (ev: PointerEvent): void => {
    const hit = ev.target instanceof Element ? ev.target.closest('button[data-i]') : null;
    if (!(hit instanceof HTMLButtonElement)) return;
    ev.preventDefault();
    emit({ kind: 'choice', index: Number(hit.dataset.i), t: ev.timeStamp });
  };
  options.addEventListener('pointerdown', onDown);

  return {
    render(s) {
      rule.textContent = s.rule === 'color' ? '按颜色' : '按字义';
      word.textContent = s.word === null ? '＋' : STROOP_COLORS[s.word].name;
      word.style.setProperty('--ink', s.ink === null ? WHITE_TEXT : STROOP_COLORS[s.ink].css);

      // 键必须同时含按钮顺序与文字墨色：按钮标签每轮固定（只由调色板决定），
      // 只用标签做键的话第 9/10 档的干扰色文字就不会刷新。
      const key = `${s.options.map((o) => o.colorIdx).join(',')}|${s.options.map((o) => o.textInk ?? '').join(',')}`;
      if (key !== layoutKey) {
        layoutKey = key;
        buttons = s.options.map((o, i) => {
          const b = document.createElement('button');
          b.type = 'button';
          b.className = 'stroop-choice';
          b.dataset.i = String(i);
          b.textContent = o.label;
          return b;
        });
        options.replaceChildren(...buttons);
      }
      s.options.forEach((o, i) => {
        buttons[i].style.setProperty('--ink', o.textInk === null ? WHITE_TEXT : STROOP_COLORS[o.textInk].css);
        // 类名逐次重算：反馈只在 200ms 内出现，复用节点时不能残留上一次的 right/wrong
        buttons[i].classList.toggle('right', s.feedbackChoice === i && s.feedbackOk);
        buttons[i].classList.toggle('wrong', s.feedbackChoice === i && !s.feedbackOk);
        buttons[i].classList.toggle('locked', s.phase === 'fixation');
      });
      info.textContent = `第 ${s.trialNo}/${s.trialsTotal} 试次　正确 ${s.correctCount}　超时 ${s.timeoutCount}`;
    },
    destroy() {
      options.removeEventListener('pointerdown', onDown);
      root.remove();
    },
  };
}

import { describe, expect, it } from 'vitest';
import { SessionRunner } from '../core/session';
import { MemoryRepository } from '../core/storage';
import type { GameState, Mode, TrialRecord } from '../core/types';
import { correctSlot, type StroopSnapshot } from './engine';
import { stroop } from './index';

const NOW = new Date(2026, 9, 18, 10, 0).getTime();
const st = (level: number): GameState => ({
  gameId: 'stroop',
  level,
  passStreak: 0,
  failStreak: 0,
  lastPlayedDayKey: null,
});

interface Cell {
  onset: number;
  rt: number | null;
  correct: boolean;
  rule: 'color' | 'word';
  conflict: boolean;
}

const tr = (t: TrialRecord): Cell => t as unknown as Cell;

const fast = (): number => 100;
// 「难题」= 按颜色时的冲突试次 + 按字义时的一致试次；难题慢 200ms
const slowIfHard = (s: StroopSnapshot): number => {
  const hard = s.rule === 'color' ? s.conflict === true : s.conflict === false;
  return hard ? 300 : 100;
};

const target = (s: StroopSnapshot): number => (s.rule === 'color' ? s.ink : s.word);
const wrongSlot = (s: StroopSnapshot): number => s.options.findIndex((o) => o.colorIdx !== target(s));

interface Play {
  delayOf?: (s: StroopSnapshot) => number;
  slotOf?: (s: StroopSnapshot) => number;
  answer?: boolean;
  // 命中一次就作废当轮（只作废一次），用于验证补轮沿用轮号
  voidOnce?: (roundNo: number, answeredInRound: number) => boolean;
}

// 固定 100ms 帧率驱动整次训练：先取快照再喂帧，所以「作答帧」总比 onset 晚一帧，
// rt 恰好等于 delayOf 给的毫秒数。轮结束或作废后在同一帧立即 beginRound。
function playSession(state: GameState, seed: number, p: Play, mode: Mode = 'plan'): SessionRunner {
  const delayOf = p.delayOf ?? fast;
  const slotOf = p.slotOf ?? correctSlot;
  const answer = p.answer ?? true;
  const runner = new SessionRunner(stroop, state, mode, seed, NOW);
  let t = 0;
  let voided = false;
  while (!runner.isFinished()) {
    runner.beginRound(t);
    let answered = 0;
    for (;;) {
      t += 100;
      if (p.voidOnce && !voided && p.voidOnce(runner.snapshot().roundNo, answered)) {
        runner.voidCurrentRound();
        voided = true;
        break;
      }
      const s = runner.engine.snapshot() as StroopSnapshot;
      if (s.done) break;
      if (answer && s.phase === 'respond' && s.onsetMs !== null && t - s.onsetMs >= delayOf(s)) {
        runner.input({ kind: 'choice', index: slotOf(s), t });
        answered += 1;
      }
      runner.tick(t);
    }
  }
  return runner;
}

    expect(record.gameId).toBe('stroop');
    expect(record.mode).toBe('plan');
    expect(record.rounds.map((r) => [r.level, r.outcome, r.counted])).toEqual([
      [1, 'pass', true],
      [2, 'pass', true],
      [3, 'pass', true],
      [4, 'pass', true],

    expect(record.rounds.map((r) => r.roundNo)).toEqual([1, 2, 3, 4]);
    expect(record.rounds.map((r) => r.seed)).toEqual([1000, 1001, 1002, 1003]);
    expect(record.startLevel).toBe(1);
    expect(record.endLevel).toBe(5);
    // 最后 ⌈4/2⌉=2 个计分轮是第 3、4 轮：mean(3-1+1, 4-1+1) = 3.5 → 35
    expect(record.ability).toBe(35);
    expect(record.rounds.every((r) => r.trials.length === 12)).toBe(true);
  });

  it('4 轮全对的结算指标：平均 200ms、干扰效应 +200ms（规则过滤漏掉会变成 +101ms）', () => {
    const { record } = playSession(st(1), 1000, { delayOf: slowIfHard }).finish('2026-10-18');

    expect(stroop.formatSummary(record.summary)).toEqual([
      { label: '正确率', value: '100%' },
      { label: '平均反应时', value: '200 毫秒' },

    ]);
  });

  it('4 轮全对的 durationMs 就是帧模型算出来的 33900ms', () => {
    // 每轮 endAt = 6000 + Σdelay：第 1/2 轮（6 冲突）Σdelay = 6*300+6*100 = 2400 → 8400；
    // 第 3 轮（7 冲突）2600 → 8600；第 4 轮（按字义，5 个慢）2200 → 8200。
    // 轮结束后在 endAt 的下一帧（+100ms）重开，3 个间隔共 300ms：

    const { record } = playSession(st(1), 1000, { delayOf: slowIfHard }).finish('2026-10-18');
    expect(record.rounds.map((r) => r.metrics.timeMs)).toEqual([8400, 8400, 8600, 8200]);

    expect(record.startedAt).toBe(NOW);

// K8：注册表增长后当天计划要能变长，但只在「今天还没打完、计划项没满 3 个、
// 且注册表里有计划外的新游戏」时重算。已打完的计划永不重算，否则没收用户今天的打卡。
export function isPlanStale(plan: DayPlan, gameIds: readonly GameId[]): boolean {
  if (isPlanComplete(plan)) return false;
  if (plan.games.length >= PLAN_SIZE) return false;
  return gameIds.some((id) => !plan.games.includes(id));
}

export function reconcilePlan(plan: DayPlan, standings: readonly GameStanding[]): DayPlan {
  if (!isPlanStale(plan, standings.map((s) => s.gameId))) return plan;
  const rebuilt = buildPlan(plan.dayKey, standings);
  return { ...rebuilt, completed: rebuilt.games.filter((g) => plan.completed.includes(g)) };
}

```ts
export async function ensureTodayPlan(
  repo: Repository,
  gameIds: readonly GameId[],
  dayStartHour: number,
  now = Date.now(),
): Promise<DayPlan> {
  const key = dayKey(now, dayStartHour);
  const existing = await repo.getPlan(key);
  // 只有注册表长出了计划里没有的游戏才重算；已打完的那天绝不动，否则没收今天的打卡
  if (existing && !isPlanStale(existing, gameIds)) return existing;
  const standings = await standingsFor(repo, gameIds);
  const plan = existing ? reconcilePlan(existing, standings) : buildPlan(key, standings);
  if (plan !== existing) await repo.putPlan(plan);
  return plan;
}

async function standingsFor(repo: Repository, gameIds: readonly GameId[]): Promise<GameStanding[]> {
  return Promise.all(
    gameIds.map(async (gameId) => {
      const [state, last] = await Promise.all([repo.getGameState(gameId), repo.lastSession(gameId)]);
      return { gameId, lastPlayedDayKey: state.lastPlayedDayKey, lastAbility: last?.ability ?? null };
    }),
  );
}
```
